# XTEINK WebSync v1.4.0

Adds a category picker for the recommended presets, 20 new presets, and fixes a case where some articles produced EPUB chapters that readers could reject.

## Presets

- The Add Site dialog now picks **category → preset** (Tech blogs / Blogs & newsletters / Life & design / Global (English)), so the list stays short as presets grow. "Custom" and "CSS manual" are always shown.
- New tech blogs with full-text feeds: Daangn, Coupang Engineering, Musinsa Tech, NAVER Cloud, Hyperconnect, Gccompany, NHN Cloud Meetup, Devsisters, Remember, Toss Feed, Yozm IT.
- New **Life & design**: Design Press, GQ Korea, Vogue Korea, Gamemeca, Uppity blog, The Edit.
- New **Global**: The Marginalian, Open Culture, Dezeen (English source; use the site's translation option to read in Korean).
- Presets whose feed only carries summaries (Kakao, LINE, Banksalad) now say so in the note.
- Political news outlets are not offered as presets; the Hankyoreh preset was removed.

## Fix: EPUB chapters with inline widgets

Article HTML that contained inline `<svg><use xlink:href>`, gallery `<button>`s, `<video>`/`<noscript>` or namespaced tags (`<o:p>`) was written into the chapter as-is, which made the chapter invalid XML ("unbound prefix"). Found with the real Dezeen feed. The sanitizer now drops those widgets, unwraps namespaced tags and removes prefixed attributes (`xml:lang` is kept).

## Tests

- Offline: feed shapes (Medium, WordPress, Atom, summary-only) go through `RssScraper` and `EpubBuilder` and the EPUB is checked structurally; code blocks, tables and entities survive; images/tracking pixels are dropped when images are off.
- Catalog contract: unique https URLs, valid categories, no political outlets, English presets carry the translation note.
- Opt-in live contract (`WEBSYNC_LIVE_CONTRACTS=1`): every RSS preset is fetched and built into an EPUB; all 27 pass.
