# XTEINK WebSync v1.4.1

This maintenance release improves device downloads, scheduled sync and cancellation, and includes fixes from the latest code audit.

## Fixes

- Device downloads avoid accidental overwrites, sanitize device-provided filenames, and handle conflicts that arise during download.
- Scheduler registration and removal report failures more clearly and handle platform-specific command output and lifecycle errors more safely.
- Cancellation is honored during translation and AI summary processing.
- Generated EPUB filenames and OPDS titles use consistent naming, and configuration normalization updates the revision correctly.
- Translation and Calibre watch retry handling are more robust.

The release also includes lint fixes, formatting, and expanded regression coverage.
