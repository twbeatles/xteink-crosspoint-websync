# XTEINK WebSync v1.4.2

This release fixes invalid EPUBs ("broken book" on the reader), makes uploads and background work more resilient, and tells you exactly which sites failed so you can retry them.

## Fixes

- Fixed invalid EPUBs missing `nav.xhtml`: HTML comments (e.g. Naver smart-editor markers) are stripped during sanitizing, and a failed EPUB write now aborts instead of sending a broken book to the reader.
- Uploads retry transient errors (timeouts, connection drops, 429/5xx) and honor cancellation for pending transfers without killing in-flight ones.
- After a sync with failures, the app shows which sites failed with guidance and offers an immediate retry; failed articles are retried automatically on the next sync.
- Local sidecar import no longer overwrites concurrent configuration changes, and shared-folder writes use unique temp files.
- AI summary honors cancellation and per-article budgets like translation already did.
- History view shows the latest row per URL deterministically, dashboard routes ignore query strings, and macOS notifications escape backslashes correctly.

If a broken book from an older version is already on your reader, update the app, delete its entry in the History tab, and sync again.

The release also includes expanded regression coverage for the Naver collection-to-EPUB chain, upload retries, cancellation, and response-loss behavior.
