# XTEINK WebSync v1.3.3

This release fixes two regressions reported after v1.3.2.

## Changes

- Fix Korean site names disappearing from device-side transfer filenames. Upload names stay ASCII-safe for CrossPoint firmware, but Hangul is now romanized (`websync/upload/romanize.py`) instead of stripped, so `네이버뉴스_2026-07-31.epub` arrives as `neibeonyuseu_2026-07-31_<hash>.epub`. EPUB titles and local filenames keep their original language.
- Fix the Windows GUI font: Malgun Gothic is now enforced on dropdown lists, tree views, tooltips, context menus, and ttk widgets, not just on buttons and labels.

## Verification

- New regression tests: `tests/test_gui_font.py` (9 checks) and a romanized-filename case in `tests/test_uploader_sanitize.py`.
- Full Linux suite and Windows platform contracts pass; the release workflow rebuilds and smoke-checks the signed-update executable before publishing.
