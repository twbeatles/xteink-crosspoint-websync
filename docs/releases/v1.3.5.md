# XTEINK WebSync v1.3.5

This release completes the functional audit fixes and documents recovery behavior for interrupted local work.

## Changes

- Validate imported site settings before saving; preserve invalid configuration for explicit recovery instead of silently replacing it.
- Prevent sanitized device upload names from colliding, and reject duplicate names in manual multi-file batches before any upload begins.
- Keep feeds with identical display names separate throughout preview, digest, selection, and upload flows.
- Persist Calibre Watch upload jobs and retry failed device targets after restart while retaining already completed targets.
- Document a project development default that does not invoke Spec Kit unless the user asks for it.

PC-to-PC exactly-once delivery still requires a server and device-side idempotency support; this release documents the design and verification procedure without claiming that guarantee.
