# XTEINK WebSync v1.3.2

This release contains the fixes from the functional audit and a smaller routine CI workflow.

## Changes

- Preserve concurrently edited site settings while publishing shared backups. Per-installation snapshots help recover changes after cloud-file conflicts.
- Restore translation with googletrans 4.0.2's asynchronous API.
- Scope cancellation to the accepted job, and wait for local work and backup flush when closing the GUI.
- Add dashboard cancellation and clearer status handling. Bound HTTP request bodies and stabilize local server shutdown.
- Embed supported article images inside EPUB files for offline reading, with size and count limits.
- Use ASCII-safe transfer filenames with a hash of the original name; keep the original EPUB title.
- Isolate test storage from user settings and history.

Routine CI now has two jobs: the full Linux suite and focused Windows platform contracts. The release workflow runs the Windows suite again before building and smoke-checking the signed-update executable.

Cloud-folder snapshots provide eventual recovery, not a global lock across PCs. Keep one PC's automatic delivery enabled per reader and let the cloud client finish syncing before switching PCs. Actual reader firmware, native GUI, and external service behavior require testing in those environments.

See [implementation and verification details](https://github.com/twbeatles/xteink-crosspoint-websync/blob/main/docs/AUDIT_IMPLEMENTATION.md).
