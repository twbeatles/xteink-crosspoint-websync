# XTEINK WebSync v1.3.6

Device transfer filenames now preserve the original blog name as set in the app, instead of romanizing it.

## Changes

- Transfer filenames preserve the original site name (including Korean), replacing only filesystem-forbidden characters, plus the original-name hash; EPUB titles already preserved their original language and are unchanged.
- Romanized names (e.g. `neibeonyuseu_...`) are no longer generated for new uploads. Files uploaded by earlier versions keep their old names on the device; they can coexist with the new names, so remove the old romanized copies from the device file tab if needed.
- Existing ASCII basenames keep their transfer naming behavior.

## Verification

- Full local suite: 620 passed, 1 skipped on Windows.
- Focused regression: uploader sanitize, uploader, CrossPoint HTTP contract, batch preflight, device client, EPUB builder, i18n guard, documentation encoding.
- Main-branch CI runs on push; the release workflow performs its own Windows tests, signed manifest build, executable smoke check, and publication.
